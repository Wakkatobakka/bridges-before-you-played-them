# Age of Empires II Mobile ExEn runtime
Portable ExEn VM adapted from Handyplay / mohamedahmed166e, pinned upstream
460b149302e9a52523bc314a37efabbee9f3d666, AGPL-3.0. See LICENSE-AGPL-3.0.txt.
Reuses the private Crash/South Park full-width arrays, String conversion,
original-font separation, canonical pen color, dialog and FIFO/timing repairs.
Graphics.drawImage now honors original palette-alpha on composited render
targets without source index buffers. This corrects the original game's generated
240x120 minimap; decoded images retain index-based transparency unchanged.
No original bytecode/assets/logic or progression is patched.
