The 31 sound.bar resources comprise 2 exact MIDI payloads and 29 QCELP payloads decoded to original-rate mono 8 kHz signed 16-bit PCM. Asset names hash the exact native-provided bytes. Android MediaPlayer completion/start/error notifications enter the native event worker. Host tests exercise callbacks using actual asset durations, not audio playback.

Detailed diagnostics OFF for gameplay. The original software 3D renderer can execute millions of interpreted ARM instructions per callback; desktop virtual-clock timings are not Android performance. Pixel delivery uses changed revisions. All native CPU/timers/input/audio callbacks and save operations share one worker. Only due scheduled ticks pump timers. Report assembly and public file writing are separate executors, reading the last completed result; report output remains usable while the game worker is occupied.
