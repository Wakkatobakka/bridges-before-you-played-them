This normalization uses v0.0.7 as its base. The supplied project checkpoint was v0.0.6; the later private checkpoint was found while locating the original signing key. v0.0.7's motion-setting commit/reader restoration and CP932 Japanese text fixes are preserved.

## What changed

- Launcher icon, title, DoJa platform label and a visible SAVE REPORT button fit the original 44dp header allocation.
- SAVE REPORT writes directly to `Downloads/Chokkan_Crash_Bridge/` using the actual UI kit v1.1.2 exporter. It does not open a file picker, release gameplay holds, pause the game or require the game worker to answer.
- Reports contain a dated published runtime snapshot, fresh worker state/stack, live counters and recent persistent log tails. Snapshot age and unavailable state are explicit.
- Fault capture is installed before gameplay View construction; faults retain local evidence and attempt independent export.
- Android system Back and Close game run real input/audio/game cleanup, finish the Activity and return to the caller, including Omni Player.

## Preserved gameplay

All existing control positions, sizes, labels, input mappings, pad sliding/diagonal behavior, multi-touch aggregation, hammer TAP behavior, quiz answers/BRIGHTEN and original softkeys remain intact. TOUCH/MOTION keeps its original visible position, mode requests, tilt/shake sensitivity, recentering and sensor lifecycle.

The game viewport retains the exact existing position, dimensions, native 240x320 proportions and per-profile scaling formulas. Chokkan's original custom canvas remains responsible for its layout. The shared viewport/control planners are not substituted.

Original `game.jar`, `game.dex`, `initial.sp`, v0.0.7 `game-compat.dex` and its charset manifest are byte-identical to the v0.0.7 APK. Renderer/audio implementations and `ChokkanInput.java`/`ControlProfile.java` are unchanged. The accelerometer remains an adaptation of the original SH904i camera gesture readers.
