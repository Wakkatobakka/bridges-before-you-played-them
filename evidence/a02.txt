WHY THE MASK MATTERS
The mask clears the counter's least significant bit. For example:

    Raw counter:    0, 1, 2, 3, 4, 5
    Masked result:  0, 0, 2, 2, 4, 4

The underlying 64 Hz tick period is 15.625 ms. The masked counter changes only
every 31.25 ms, in increments of two. It still represents approximately 64
tick units per second: this is reduced resolution, not a clock running at
half speed. With game callbacks near 60 per second, many successive reads
produce a zero elapsed-tick delta, followed by a two-tick delta.

The original Ashen timestep calculation accepts zero elapsed time. The
pre-change phone trace showed its movement command clearing after release
while the player's position continued changing. Input release delivery was
not the cause demonstrated by that trace.
