LAUNCH CRASH FIX — v0.1.2

Device evidence: supplied Samsung screenshot says Sonic N closed because of
an app bug. The recovered 6.47-second recording shows repeated icon taps and
immediate returns to the launcher before the gameplay screen appears.

REPRODUCED ROOT CAUSE
Production MainActivity.onCreate builds BridgeGameplayUi before setContentView.
In the supplied v1.1.0 kit, setupWindowInsets calls Window.getInsetsController
before PhoneWindow decor is created, causing a NullPointerException in
PhoneWindow.getInsetsController. This exact exception is reproduced with the
actual MainActivity and real compiled resources under Android API34 framework
callbacks/Robolectric 4.16.1. The generic already-created-Activity shell test and
pure geometry/input checks did not exercise this lifecycle ordering.
