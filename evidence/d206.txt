The current Omni capability contract already includes the required gzip-CMID-to-MIDI/PCM converter under legacy-audio-v1, preparation id m-orcs. Its input filename is fixed by that existing generic implementation. Consequently orcsandelves2.bar is a preparation-only alias whose complete SHA256 equals doom2rpg.bar. It contains DOOM II RPG's supplied original BAR, with no Orcs game code or assets. The actual runtime reads doom2rpg.bar only. Using the verified alias avoids asking the owner to change Omni or executing a new checkpoint script on the phone. No new unsupported recipe/action is declared.

Preparation inventories pin all 143 unique output assets. MIDI outputs use exact hashes. WAV outputs use verified-source-pcm-v1 with original encoded-source fingerprint, canonical desktop PCM reference, channels/rate/bits/frame count. Public reconstruction produced byte-identical MIDI and equivalent canonical PCM on the host. Actual phone architecture decoding remains a separate acceptance check.
