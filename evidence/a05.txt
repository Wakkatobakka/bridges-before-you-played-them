UPSTREAM IMPLEMENTATION SCOPE
The tested runtime belongs to a dedicated Ashen bridge. Removing this mask
there changes its EKA1 counter generally; the binary instruction itself is
not guarded by Ashen's UID. For a multi-game EKA2L1 release, a title-specific
compatibility option/profile for Ashen (UID 0x101FD3E9) is the appropriate
next implementation to evaluate. Preserve the Worms workaround for the game
that needs it until broader regression tests establish a safe default.
There is no claim that the same change fixes every slippery game.
