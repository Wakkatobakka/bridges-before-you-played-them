CONTROLS
Slide your thumb on the four-way digital D-pad to move forward/back and turn.
4/6: strafe. 2/8: look up/down. 1: jump. 3: use/pick up/interact.
5: right action (weapon/spell). 7: left action (consumable).
*/0: cycle action queues. #: character manager. 9: map.
MENU L and MENU R: original pause/save menu.
The original Options > Controls menu can customize game bindings.
Tap the always-visible ORIGINAL KEYPAD button to change the inline controls;
D-PAD RETURN restores the normal panel. Both modes retain the full original
D-pad. Keypad mode has the original 15-key cluster and large 5/7 action aliases.
Both modes share one measured slot, keeping the same live renderer attached.
Switching releases touch holds while preserving physical-controller holds.
Android Back closes gameplay. Save in the original game first.
