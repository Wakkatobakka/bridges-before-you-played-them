CONTROLS
Original numeric directions are 2/8/4/6. The digital D-pad supports continuous
sliding and the existing simultaneous cardinal combinations. Power/Throw is
numeric 5: hold to build power, then release to throw in catching missions.
Select is original ExEn -8; Pause is -7. The original game explains each mission.
Original Keypad switches inline with one tap. Its numbers replace the numeric
D-pad; this game does not have a second separate directional input group.
Select, Pause, Power/Throw and 0 remain directly available in both modes.
D-PAD RETURN switches back without pausing or recreating the game.
Owned touch and physical sources protect overlapping holds and release orders.
Android Back runs real worker cleanup and exits to the caller, including Omni.
