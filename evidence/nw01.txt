Original: MainApp MIDlet, MIDP 2.0 / CLDC 1.0, native 240x320. Classes a-j are
obfuscated and reuse field names with different descriptors. Reflection-based
state evidence must select fields by name AND type, never getField(name) alone.
The original i Canvas starts its update thread from MainApp's constructor;
initialize platform and save directory before constructing the MIDlet.

MIDP implementation reused from the recent Ratchet J2ME work; required Nowhere
additions are mutable images, byte-array PNG images, Graphics.clipRect and all
8 drawRegion transformations, Canvas.getGameAction, Display.vibrate acceptance,
Player.getState/removePlayerListener, and RMS.getRecord returning bytes.
Zero-size drawRegion is a no-op. Treating it as an error killed the original
worker at the first room transition; that compatibility defect is fixed.
