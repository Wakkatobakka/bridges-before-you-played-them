REUSABLE WORK AND VERIFICATION LIMITS
The host probe forks the supplied BioShock 3D v0.2.0 ARM/BREW runtime, using
Kingdom Hearts package/class identification and its own diagnostic heading.
Its BioShock-specific game-state memory observer was disabled. It executes
original ARM instructions; the original game bytes are unchanged. The probe
reproduces the startup boundary and explicitly checks that gameplay did not
start. It is not a complete Swerve or Kingdom Hearts runtime.
