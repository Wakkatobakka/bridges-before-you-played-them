SELECT 5 confirms ordinary selections; OK/NEXT is the original validation
softkey. Left/right changes an arrowed menu value; down/validation commits the
choice. Campaign map generation retains original timing and can take a while.
The normal eight-way digital pad sends exact diagonal digits 1/3/7/9.
MAP 0, BUILD #, contextual UNITS *, and original BACK/MENU are directly usable.
ORIGINAL KEYPAD and D-PAD RETURN switch inline with the same live viewport.
Android system Back closes the game. SAVE REPORT writes to Downloads/Age of
Empires II ExEn Bridge/ independently of the game worker.
