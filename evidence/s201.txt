Base: Katamari v0.1.0 CPU/BREW interpreter and Genesis-style Android presentation. No unrelated game is packaged.

The original game module maps at 0x00100000. Its CreateInstance comparison establishes class ID 0x010279D7. When it requests Micro3D class 0x0101F0AA, the host maps the supplied `imicro3d.mod` at 0x00300000 with its own system-table prefix and invokes its original AEEMod_Load and module factory. Nested guest invocations preserve outer registers, flags, instruction mode and use a lower stack. No module instructions or game state are patched.
