The original 137168-byte 2008 ARMv5/Thumb module runs in the Java BREW
compatibility layer. The core comes from the clean BioShock v0.2.0 lineage,
including Contra's native timer deadlines and exact bitmap memory watches;
the UI follows Resident Evil Genesis. It does not reuse the old hot BioShock
v0.1.7 build. No gameplay is reconstructed and no game instructions are patched.

TITLE INTEGRATION
Class ID 0x0106CC3B, native framebuffer 240x320. Selected module/resource.bar
are byte-identical across the unnumbered and screen-capture variants. Clean
MIF/icon comes from the latter. All three exact original ZIPs are retained;
the other 2009 variant has different native maps and archived player progress.

Existing runtime gzip sources, original BMP decode/palettes and native file
services cover this resource.bar. Katamari adds the display/font measurement
services, original SoundPlayer memory-source handling, the optional original
0x01005000 query, and graphics circle/ellipse rendering. Circle/ellipse
outlines honor no-fill mode; border thresholds are calculated once per draw.
