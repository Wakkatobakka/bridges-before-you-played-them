Original native event semantics: EVT_KEY_PRESS 0x101 sets pending down bits at
applet+0x498; EVT_KEY_RELEASE 0x102 sets release bits at applet+0x49C. The native
timer consumes these. Production input queue prevents short taps from disappearing
by retaining down through one naturally due native callback. Every edge is retained;
releaseAll releases immediately during background/focus loss. No Katamari-specific
modal memory offsets or control descriptions are used for game routing.
