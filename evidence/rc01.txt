Omni's initial result was missing execution capability, not a demonstrated game bug.
It preserved and inspected the package but had no matching adapter.

Runtime
The bridge executes all eleven original game classes and original resources.
Compatibility APIs cover MIDP display/canvas, Nokia DirectGraphics, media,
record stores, and the original native text-entry form/alert path.
The font vectors f3.v/f4.v are drawn by original game code. System substring
fallback uses the original vector font. The original launcher icon is retained.

A concrete startup incompatibility was resolved: original font/audio loading uses
System.out.getClass().getResourceAsStream. Bootstrap classes cannot locate app
resources on a desktop JVM. PatchGuest redirects only those resource calls through
the application resource loader and adds observational caught-exception hooks.
