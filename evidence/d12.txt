PRESERVED RUNTIME
The original host APK is in baseline/Dirge_Bridge_v0.2.4.apk. Its old
GameActivity family is exposed as BaseActivity and inherited by the new UI
Activity. Existing runtime method bodies are not recompiled or rewritten.
All 662 retained methods match after final D8 packaging, including original
boot, surface, graphics, audio, input sampling, aim repair, saves and teardown.

Only the existing MainActivity family (version/routing) and TwinLayout family
(touch geometry) are replaced. TwinInput and CameraAssist are preserved from
v0.2.4, including the runtime PAD_LEFT/PAD_RIGHT field reads that repaired aim.
Old runtime report sections still identify their frozen v0.2.4 baseline; the
new report header identifies app 0.3.0 / UI Kit 1.1.1 explicitly.
